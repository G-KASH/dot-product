Project Title: Array Algorithms in JavaScript
🔍 Description:
This project demonstrates two fundamental algorithmic problems using HTML, CSS, and JavaScript:

✅ Problem 1: Sum of Distinct Elements
Goal: Given two arrays (sets), compute the sum of all distinct elements (i.e., elements that appear in only one of the sets).

Approach:

Loop through each set.

Add elements to the sum only if they do not appear in the other set.

Example:

Set 1: [3, 1, 7, 9]

Set 2: [2, 4, 1, 9, 3]

Distinct elements: 7, 2, 4

Output: 13

✅ Problem 2: Dot Product & Orthogonality Check
Goal: Determine whether two vectors are orthogonal using the dot product.

Dot Product Formula: dot(v1, v2) = v1[0]*v2[0] + v1[1]*v2[1] + ... + v1[n]*v2[n]

Orthogonality Rule: If the dot product is 0, the vectors are orthogonal.

Approach:

Use a loop to compute the dot product.

Check if the result equals 0.

Supports multiple vector pairs for checking.

🎨 Styling:
CSS is used for visual formatting.

Result outputs are styled with color for better clarity (e.g., green for orthogonal, red for not).
